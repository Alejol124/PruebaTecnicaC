Ejercicios
1.Se construye un grafo dirigido a partir de una lista de conexiones (edges).
Se implementa un método que determina si es posible llegar desde un nodo de origen 
hasta un nodo destino recorriendo el grafo, utilizando una cola y un conjunto de nodos visitados.

2.Se simula una cola de personas donde pueden ocurrir eventos aleatorios como la llegada 
de una persona, la atención de la primera en la fila o que no ocurra ningún evento.
Se utiliza la estructura de datos Queue para respetar el orden de llegada (FIFO)

3.Se valida si una expresión está correctamente balanceada usando paréntesis (), 
llaves {} y corchetes []. Se emplea una Stack para verificar que cada símbolo de 
cierre corresponda con el último símbolo de apertura.

4.Se simula la respuesta de una API en formato JSON. Filtrar los elementos según reglas,
Transformar el resultado a una estructura más simple y Limpiar los datos eliminando cualquier 
clave que contenga _
